# Building 100 · Materials Warehouse

Interactive 3D model of a materials warehouse and its open yard, with forklifts, drones and a named team in a live simulation, plus stock search and a guided tour. Runs in any browser.

Live: https://a-a-a124.github.io/building100/

Concept model. Material numbers and quantities are illustrative sample data.
