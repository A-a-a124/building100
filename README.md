# Building 100 · Materials Warehouse

Interactive 3D model of a materials warehouse and its open yard, with forklifts, drones and a named team in a live simulation, plus stock search, Excel import, slotting suggestions, scenario comparison, occupancy forecast, safety analytics, walk mode and an Arabic interface. Runs in any browser.

Live: https://a-a-a124.github.io/building100/

Concept model. Material numbers and quantities are illustrative sample data.

Designed by Abdullah Aladhyani.
